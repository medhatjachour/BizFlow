## `src/plugins/` — Plugin Backend

### Plugin Structure (every plugin)

```
src/plugins/<name>/
  index.ts          # IPlugin: { id, ensureSchema(), registerHandlers() }
  manifest.ts       # Metadata: name, description, features, icon
  migrate.ts        # ensureSchema() — checks sqlite_master + db push if missing
  preload.ts        # ipcRenderer.invoke() wrappers exported as <name>Preload
  schema.prisma     # Plugin Prisma models (NO datasource/generator blocks)
  handlers/         # One .ts file per handler domain
```
